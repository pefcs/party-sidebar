# Party Sidebar

Adds a customizable party sidebar to Foundry VTT, displaying character portraits, HP, AC, movement, and active effects.

## Controls
- **Grip:** drag to reposition the sidebar vertically or anywhere when unlocked.
- **Lock (left-click):** undock/unlock the sidebar; left-click again to lock its free position.
- **Lock (right-click):** re-dock beside Foundry's right sidebar.
- **Orientation:** switch between vertical and horizontal layouts.
- **Up / Down:** nudge the sidebar vertically.
- **Settings:** portrait size and the docked vertical offset remain configurable in Foundry's module settings.

Position, lock, dock, and orientation preferences are stored locally for each client.
