# Party Sidebar

Adds a customizable party sidebar to Foundry VTT, displaying character portraits, HP, AC, movement, and active effects.

## Controls
- **Grip:** drag to reposition the sidebar when unlocked.
- **Lock (left-click):** undock/unlock the sidebar; left-click again to lock its free position.
- **Lock (right-click):** re-dock beside Foundry's right sidebar.
- **Orientation:** switch between vertical and horizontal layouts.
- **Configuration:** open the popup with live portrait-size and vertical-position sliders.
- **Collapse:** turn the entire sidebar into a single party icon. Click that icon to restore the sidebar.

Position, lock, dock, orientation, and collapsed/expanded preferences are stored per client and persist across reloads.

## Visual theme
The sidebar uses the shared Action HUD / Roll Director palette: charcoal surfaces, slate borders, teal accents, off-white text, and warm gold highlights.
